# Data sources

- Use the NVD CVE API 2.0 for disclosures, published and modified times, source metrics, applicability and references. [NVD vulnerability API](https://nvd.nist.gov/developers/vulnerabilities)
- Use the official CPE Dictionary and Match Criteria APIs for canonical identifiers and scoped reconciliation. [NVD product APIs](https://nvd.nist.gov/developers/products)
- Preserve the CVSS version and metric source, prefer version 3.1 for the demonstration and document the deterministic source selection order before implementation. [FIRST CVSS](https://www.first.org/cvss/)
- Use explicitly labeled fictional inventory, analyst and remediation fixtures. Keep verification linked to authentic applicability and the supplied inventory snapshot.
