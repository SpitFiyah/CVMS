# Contributing

Preserve existing work on the target repository and use reviewed feature branches against its integration branch. Link each pull request to its issue and include commands and observed results. Run the Python suite locally and run Oracle changes in a dedicated Oracle 11g XE schema. Update the relational documentation and both copies of the Mermaid ER diagram when changing the data model.

The Mermaid Actions job renders the standalone ER source and the Mermaid blocks in the ER and architecture Markdown files. Developers can use the same `mmdc` commands from the workflow locally. [Mermaid CLI](https://github.com/mermaid-js/mermaid-cli)
